# mechanistic-tomato-crop-model
Mechanistic dwarf tomato growth &amp; water-use model in Python, calibrated using WUR 4th Autonomous Greenhouse Challenge datasets. Built for controlled environment agriculture modeling.

## Data Provenance & Attribution

The climate and harvest datasets included in `data/` are derived from the open-access **4th International Autonomous Greenhouse Challenge** conducted at Wageningen University & Research (Bleiswijk, The Netherlands, 2024):

* **Source Repository:** 4TU.ResearchData ([DOI: 10.4121/fa102772-32db-4b30-bace-12f2016722ce](https://doi.org/10.4121/fa102772-32db-4b30-bace-12f2016722ce.v1))
* **Primary Citation:** Maree, S. C., Zhang, P., van Marrewijk, B. M., de Zwart, F., Bijlaard, M., & Hemming, S. (2025). Autonomous Greenhouse Cultivation of Dwarf Tomato: Performance Evaluation of Intelligent Algorithms for Multiple-Sensor Feedback. *Sensors*, 25(14), 4321.
* **License:** Creative Commons Attribution 4.0 International (CC BY 4.0).
* **Extraction Pipeline:** See `notebooks/extract_data.ipynb` for raw-to-processed transformation logic.
